Podcast: Microsoft CTO Kevin Scott — An Internet Made for Agents / 播客：Microsoft CTO Kevin Scott——为 Agent 而建的互联网

AI & I 采访 Microsoft CTO Kevin Scott，论 agentic web、MCP 协议、capability overhang、agent 身份与安全模型、工匠精神与异步 agent 未来。完整 transcript（29372 字符）已翻译。

A&
AI & I by Every (Dan Shipper)
Kevin Scott（Microsoft CTO）
中文

AI & I：Dan Shipper 采访 Microsoft CTO Kevin Scott。核心话题：agentic web 是今年的大故事（agent 需要一个像互联网的生态——MCP 扮演 HTTP 的角色，NL Web 扮演 HTML 的角色）；capability overhang（模型推理能力已领先于产品交付——全行业需要共同缩小差距）；agentic memory（如今的 agent 是事务性的，任务后记忆消失，阻碍委派复杂工作）；康威定律风险（你发布的是你的组织架构图——Microsoft 推动内部所有系统对 agent 说标准协议）；MCP 安全模型（agent 需要身份和权限——「这个 agent 代表这个人行动，有权访问这些资源」）；无许可创新 vs 看门人（不为创造者和用户创造价值的中间层）；AI 辅助个人安全（监控你的通信渠道并三角验证可疑活动的 agent，如他妻子的 2FA 事件）；工匠精神与选择（木工辩论手工 vs 电动 vs CNC = 程序员辩论编辑器和 agent——「保持好奇，去尝试」）；以及异步 agent 未来（「去把这事搞定」——agent 长时间迭代后再交还控制权）。

【agentic web 与协议层】

Scott：如果 agent 要有用，它们必须能代表你行动。需要一个像互联网的生态系统。

「MCP 在 agentic web 中扮演 HTTP 在互联网中的角色。NL Web 则是 HTML 的精神等价物。」

「模型的推理能力已经领先于产品中使用它们的方式。我们全行业需要缩小这个差距。」

【记忆与康威定律】

Scott：我们的 agent 现在有点事务性——完成一个任务后记忆可能就消失了。下次从头开始。这阻碍委派复杂任务。

「康威定律说你发布的是你的组织架构图。我推动 Microsoft 内部所有系统对我们的 agent 说标准协议，避免这种悲剧。」

【安全模型与无许可创新】

Scott：agent 需要身份，才能建权限系统。这个 agent 代表谁行动、有权看哪些资源。

「开放系统的无许可创新是最令我兴奋的。不需要向看门人申请就能创建和分发。」

「一些中间层对创造者和用户都没有创造价值。不会长久的。」

【工匠精神与选择】

Scott：我做木工的时间和写程序一样久。当年的辩论是用电动工具的算不算真木工——现在是用 CNC 算不算。

「我仍然用 vi。我知道这不是最优选择，但我有得选。重要的是保持好奇，去尝试。适合就用，不适合就不用。」

【异步 agent 未来】

Scott：现在大家是同步模式——发 prompt、等结果。明年会转向异步：「去把这事搞定」。

「Agent 会花很长时间，调用很多系统，迭代多次，然后在某个时刻说：我到这里了，轮到你了。」

English

AI & I: Dan Shipper interviews Kevin Scott, CTO of Microsoft. Key topics: the agentic web as this year's big story (agents need an ecosystem like the internet — MCP plays the role of HTTP, NL Web the role of HTML); capability overhang (model reasoning has gotten ahead of what products deliver — the industry must close the gap); agentic memory (today's agents are transactional, memory goes away after the task, which inhibits delegation of complex work); Conway's Law danger (you ship your org chart — Microsoft pushes all internal systems to speak a standard protocol to agents); MCP security model (agents need identities and entitlements — 'this agent acts on behalf of this person and is entitled to these resources'); permissionless innovation vs gatekeepers (middle layers that don't add value to creators and users); AI-assisted personal security (an agent that monitors your communication modalities and triangulates suspicious activity, like his wife's 2FA incident); craft and choice (woodworkers debating hand tools vs power tools vs CNC = programmers debating editors and agents — 'be curious, try stuff'); and the async agent future ('go sort this out' — agents iterating for long periods before returning control).

Kevin Scott: I've been talking a lot lately about this thing called the capability overhang. We have some work to do collectively to close the gap between what the models are capable of and what we're delivering to users.

Kevin Scott: MCP is serving the same purpose in this agentic web as HTTP does on the internet. NL Web is the moral equivalent of HTML.

Kevin Scott: We're not exposing the entire world to Conway's law. You ship your org chart.

Kevin Scott: We need agents to have identities, so that you can build entitlement systems.

Kevin Scott: I've been a woodworker for almost as long as I've been a programmer. Are you a real woodworker if you use CNC tools?

Kevin Scott: You're going to start getting to the point where you're able to go from this synchronous mode of interaction with agents to asynchronous.
