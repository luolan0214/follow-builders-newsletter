Podcast (Re-run): Kevin Scott — An Internet Made for Agents / 播客（重播）：Kevin Scott——为 Agent 而建的互联网

AI & I 的 Microsoft CTO Kevin Scott 一期在 feed 中重播（与 2026-08-14 期相同，2026-08-12 发布）。完整 transcript（29372 字符）译文随卡附上。

A&
AI & I by Every
Kevin Scott（Microsoft CTO）· 重播
中文

今日 feed 播客位为重播：AI & I 与 Microsoft CTO Kevin Scott 的对话（本刊 2026-08-14 期已完整收录，2026-08-12 发布）。核心看点：agentic web 是今年的大故事——MCP 扮演 HTTP、NL Web 扮演 HTML；capability overhang 需要全行业缩小差距；agent 记忆的事务性阻碍复杂委派；康威定律风险（你发布的是你的组织架构图）；agent 需要身份与权限系统；无许可创新击败看门人中间层；木工 CNC 之辩映射程序员 agent 之辩；异步 agent 未来（「去把这事搞定」）。完整译文见下。

【工匠精神与选择】

Scott：我很高兴我的员工——广义的制造者，软件工程师、机械工程师、木匠、陶艺师——如果你真心热爱你所做的事，你会有非常强烈的观点，并不断打磨它。我最喜欢的木工 YouTuber 之一 Stout，他的口头禅是「买好工具，哭着也要买」。工具和手艺的关系从来不是非此即彼。

Scott：每次工具革命（CNC 数控机床进入木工房），都会有人哀叹手艺之死。但事实是：工具把重复的部分自动化，人把判断力放在选择上——选什么木料、什么榫卯、为谁而做。程序员的 agent 化也是同一件事。

【agentic web 与协议层】

Scott：今年的大故事是 agentic web。MCP 扮演当年 HTTP 的角色——一个让所有 agent 互相发现的协议；NL Web 扮演 HTML 的角色——让 agent 可读的网页。当年 web 之所以爆发，是因为协议简单、开放、无许可。agent 生态要重演这一点。

Scott：agent 需要身份与权限系统。今天的互联网是为人类设计的：登录、验证码、订阅条款。agent 需要原生的身份层，否则一切代理行为都会退化成「冒充人类」。

【capability overhang 与缩小差距】

Scott：现在的模型能力与实际部署之间存在巨大落差——capability overhang。缩小这个差距不需要新科学，需要全行业的工程努力：更好的工具、更好的记忆、更好的权限、更好的评测。这会是未来几年最大的生产力来源。

【记忆与康威定律】

Scott：agent 记忆目前是事务性的——会话结束即消失，这阻碍了复杂委派。你不能把一个为期数周的项目交给一个每隔几小时就失忆的员工。记忆、上下文管理、任务分解，是 agent 走向异步自主的三块基石。

Scott：还有组织风险：康威定律说你的系统结构就是你组织的沟通结构。如果你不主动设计 agent 与人的协作架构，你发布的就会是你现有的组织架构图——连同它的全部瓶颈。

【安全模型与无许可创新】

Scott：安全模型也要重想。今天的安全假设「用户是人类」。当 agent 代表你行动时，需要的是可撤销的、细粒度的、可审计的授权链。HTTP 时代的无许可创新击败了看门人中间层——agentic web 时代也该如此。

【异步 agent 未来】

Scott：终极愿景是异步 agent：你对它说「去把这事搞定」，然后它规划、执行、汇报。像雇用一位真正可靠的下属。我们离这个未来不远——前提是把记忆、身份、权限、评测这些无聊但关键的底座打好。
