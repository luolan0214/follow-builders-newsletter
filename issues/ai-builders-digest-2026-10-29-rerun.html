中文

Thariq 的个人实验（**8262 赞，今日最高**）——「实验一个小个人项目：AI 原生的 macOS dock——带自定义模式（写作、构建等）帮我保持专注。我的 agent 能自定义模式行为、添加新模式；它用 Jev 实时分类我的活动与通知、并据此行动。」这是他离开 Anthropic 后的首个大动作演示。配套说明（628 赞）——「这是我一直想做的 HCI 工作，但改 OS 内核向来非常耗时。还没分享——边缘情况仍很多（不建议使用），但实验很有趣！」基建思考（2465 赞）——「感觉需要一种新的开源软件分发方式：让人能用 agent 修改、又能自动把上游合并回来。编码 agent 做得到这些，但不会自动做。」

English

Thariq's personal project (8262): experimenting with a lil personal project: an AI-native macOS dock with custom modes (writing, building, etc.) to help me stay focused — my agent is able to customize mode behavior and add new modes, it uses jev to classify my activity + notifications in real time and act on them. The caveat (628): this is the kind of HCI work I've been wanting to do for a while, but messing with OS internals has always been very time consuming — not sharing yet, there are still many edge cases (would not recommend using), but fun to experiment with! And the infrastructure thought (2465): feels like there needs to be a new way to distribute opensource software such that people can modify via agents but also get upstream automatically merged in — coding agents can do this but they won't do it automatically.

Under 1% Deployed / 企业自动化不足 1%

Levie 长文（186 赞）：「绝大多数企业工作流从未真正用上 agent——经济体的部署率可能不足 1%。这不是用户提示 agent 做任务，而是组织重构底层工作流」；Amjad（**592 赞**）：「投资前沿 AI 我会主要押注新发现及其应用（如医药）——编码与多数知识工作正迅速被次前沿模型饱和」；Danshipper 双发（**442/227 赞**）。

中文

Levie 的企业现实核查（186 赞）——「没错。绝大多数企业工作流从未真正用上 agent——整个经济体的部署率现在可能不足 1%。最好的情况也就是企业里有几个自动化系统、对工作做一次单轮 LLM 判断或反馈——真正的『自动化』极少。一部分是企业技术采用速度的问题，但大头其实是 AI 自身能力的问题。这一切正在改变：现在有了 computer use、长时 agent、harness 改进与周边基建，我们终于可以开始把 agent 用到更复杂的工作流上。我们将看到自改进系统：对任意工作流目标、在一批量实例上不断提高执行率；再加上 agent 集群这个新形态——你想往问题上投多少算力都行，agent 会自己干活。这不是终端用户提示 agent 完成任务，而是组织重构底层工作流来利用 agent——对金融、生命科学、医疗与其他信息密集领域影响巨大。现在就有大量机会去构建与部署这些系统。」Amjad 的前沿投资观（**592 赞**）——「如果让我投前沿 AI，我会把定价主要押在『新发现』及其应用（比如医药）上——因为编码与多数知识工作正迅速被次前沿模型饱和。」Danshipper 双发——转发一个「极好的解释」（442 赞，本周 Every 会有更多）+ 预测（227 赞）：「视频创作与游戏制作将成为广泛分布的知识工作基础——就像今天的文档与幻灯片一样。」

Levie：经济体 agent 部署率不足 1%；未来是组织重构工作流，不是用户提示 agent。Amjad：前沿 AI 押新发现与医药——编码正被次前沿模型饱和。Shipper：视频与游戏制作将成为知识工作基础。

English

Levie's enterprise reality check (186): the vast majority of enterprise workflows have not actually had agents applied in any meaningful way — the economy probably has this deployed under 1% right now. At best a few automated systems do a single LLM pass to make a decision; very little real automation. Now with computer use, long running agents, harness improvements and surrounding infrastructure, we can start applying agents to more complex workflows: self-improving systems that improve execution rates over a volume of instances, and agent swarms where you deploy any amount of compute at a problem. This won't be end users prompting agents — it will be organizations reengineering underlying workflows, with massive impact in finance, life sciences, healthcare, and other information-heavy domains. Amjad's frontier-investing take (592): if he's investing in frontier AI he would underwrite it mostly on new discovery and its applications like medicine, because coding and most of knowledge work is quickly being saturated by sub-frontier models. Shipper's pair: an extremely good explanation he's amplifying (442), and the forecast (227): video creation and game making are going to become widely distributed foundations of knowledge work in the same way doc and deck creation are today (more coming in Every this week).
