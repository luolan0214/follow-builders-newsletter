NP
No Priors
Brian Armstrong（Coinbase 联创兼 CEO；New Limit 联创）× Elad Gil
中文

No Priors 全新一期（09-10 发布，本刊首次收录）：Coinbase 联创兼 CEO Brian Armstrong（同时是长寿公司 New Limit 联创）谈万物交易所、agentic 金融、X402 协议、公司内部的「大脑」与 RSI、代币化股票、预测市场与表观遗传重编程。完整译文见下。

【开场：万物交易所与 agentic 金融】

Armstrong：刷卡最低手续费通常是 30 美分加百分比——付 30 美分发一笔 1 美分的支付毫无意义。我们看到的统计：约 76% 的 agent 电商交易低于 30 美分。我们不想让 AI 没有银行账户——如果要给 AI 开户，它们也配得上金融服务。我们做了些简单工具：一条 prompt 粘给你的 AI agent，它就能拥有自己的金融账户——用自托管钱包与加密轨道，没有 KYC 流程：AI agent 没有政府身份证，也（暂时）没法带着人形机器人伙伴走进银行网点。不远的将来 agent 会比人多，agent 经济在某刻会比人类经济更大。

Armstrong：Coinbase 正处在激动人心的时刻。一方面所有资产类别都在上链：股票、大宗商品、加密货币、衍生品、永续期货、预测市场——都能在一个地方交易、有良好流动性与交叉保证金。第二块是稳定币支付——增长疯狂，比特币跌它也在涨：一秒之内、不到 1 美分把世界任何地方的钱转过去，钱以信息的速度流动，像 WhatsApp 消息一样。第三块是 AI 改变金融服务，我们叫 Agentic Finance 或 AIFi：①人人该有 AI 投资顾问——像富人专属顾问那样教你建组合、定投、税损收割、现金生息，用对话完成，已在产品里上线；②agent 自己要有账户——将来还会有隔离资金的 agent 子账户挂在你的身份下，也可以是纯自托管钱包，甚至能发币募资。

【X402、专业化 agent 与稀缺的未来】

Armstrong：今天的 agent 常被卡住——「这里有付费墙，请刷你的卡」「要开 AWS 资源」「订好了酒店但请你输信用卡」。将来 agent 该有自己的消费账户，像助理或员工那样；可能还需要稳定币背书的信用卡做向后兼容。我们看到大量 agent 支付跑在新协议 X402 上——那是我们在 Coinbase 孵化、捐给 Linux 基金会的，Google、Cloudflare、AWS 都在参与。我们做了个网站 agentic.market 可以看这个新经济的支付流量统计。这些小额交易多是获取信息：风投从付费数据源做研究、招聘方抓 LinkedIn 数据，很多其实是 agent 向其他专业 agent 买数据——像一次工具调用。

Armstrong：前沿模型被训练成很好的通才，但我们看到开源小模型在公司专有数据上微调或强化学习后，能在专门任务上超过前沿模型——比如拿 Coinbase 十万条合规案例训练的合规审查队列。将来市场上会出现一批专家 agent：专门帮你订披萨的、只在海量专有 Figma 数据上训练的杰出设计师……

Armstrong：Elon 说未来会没有货币——这次我不同意他（尽管多数事我都同意）。我明白他的意思：最终要用能量与质量来计量。但稀缺会长期存在：即便机器人和 AI 让商品、食品、住房变得极便宜造成通缩，土地、能源、芯片仍稀缺——戴森球在很远的未来都会很贵。所以仍需要交换媒介。AI 兴起之时，加密轨道恰好成为这一切的完美补充：加密对人类很好用，对 AI 将是必需品。

【Coinbase 内部：公司大脑与 RSI】

Armstrong：内部我们和多数公司一样从基础做起：编码工具接上数据仓库、机器学习做风控反欺诈、AI 客服。最近在推进边界的一件事：尽可能接近并真正实现递归自我改进（RSI）。给公司装「大脑」——可以是每个团队一个、每个服务仓库一个、甚至每个人一个（我认为个人大脑应该离职时可以带走，我们正在定相关政策）。

Armstrong：大脑是什么？该服务历史上所有事故、必须执行的财务控制、跑过的每个 AB 测试、完整的 GitHub PR 史（被接受与被拒的）。agent 进来改服务时先摄入大脑；人审查发现「漏了点什么」时，关键一步不是手动改掉就发布，而是把这次对 agent 思考的修正写回大脑——不只修这一个 case，而是修所有未来 case。于是单发 PR 的接受率开始随时间爬升——你就得到了一个递归自我改进系统。内部 agent 框架叫 Toshi，已集成这些工具，能对外部供应商发起调用、用 X402 协议支付。

Armstrong：今天早些时候我在为一个较复杂的功能做规划：让高端模型把功能拆成三阶段、每阶段十件事，然后执行阶段一——起 10 个并行 agent 分别干，并自行推荐合适的（更便宜的）模型——它起了一堆开源模型和 Grok。上播客前两分钟它 ping 我：阶段一全部完成、待审。这开始变得上瘾：过去我有想法或发现 bug 只能在 Slack 里整天骚扰团队，现在 @ 一个 agent，直接给团队发一个已完成的 PR 待审。

Armstrong：生产率确实在提升，但这不等于公司平均规模会变小——被自动化消灭的是任务，不是人。Coinbase 不会裁到十个人，而是现有的人能干更多、一切加速；同时两三人公司确实能做远超历史预期的事。

【万物交易所、代币化与预测市场】

Armstrong：最近财报披露：我们 88% 的收入来自非比特币交易。股价与比特币相关性还挺高——我爱比特币、它是数字黄金——但加密在更新金融系统的每个角落。刚发布的代币化股票（暂限美国以外）：第一个真正的代币化股票产品——不是合成品、衍生品或债务工具，是 1:1 托管真实证券的证券。世界上约 40 亿人没有任何券商或美股账户，没法投资 Coinbase、英伟达、苹果；正如 Tether 在美国外让美元账户普及，这 40 亿人也想要高质量投资。接下来私人信贷、国债、银行存款都会被代币化——金融服务将跑在现代轨道上；想送侄子一股股票，直接转账到他的钱包。

Armstrong：预测市场在 Coinbase 应用里增长飞快——上线数月就达到约 1 亿美元收入运行率，季度环比超 100%。体育是一部分，只是娱乐，但社会意义更大：不止选举——想评估政策？「若实施该政策，一年/两年/三年后失业率会是多少」，可以为其开预测市场辅助决策。还有人生大问题——「有神吗？我们是演化还是智能设计的？」有人叫它意见市场：没有明确的结算日，但新论文、新事件会让 60% 的共识变成 80%，人们照样能下注——就像股票也没有结算日。我们才刚挠到表面。

【New Limit：表观遗传重编程】

Armstrong：Coinbase 2021 年上市后我问自己是否要开始下一段——结论是 Coinbase 才刚开始（加密只占全球 GDP 约 0.5%），但我也想孵化些别的东西。如果靠软件赚了钱，你多少有义务把钱投进硬科技。我列了大趋势：太空、AI、聚变、脑机接口——都已有好团队；长寿领域我没看到足够多好团队，且很多是蛇油。办了几场晚宴把最聪明的 CEO 与科学家聚在一起问「什么是高潜且被低投入的」，一个反复出现的答案是表观遗传重编程——山中伸弥实验室的早期结果展示可以把细胞重编程恢复年轻功能（他们是改变细胞类型，我们不想那样）。这像 2010-11 年的比特币之于我：三个月停不下来地想。这种灵感是易腐的，要趁它消退前做点什么。于是 Jacob Kimmel（现任 CEO）、Blake Byers、Greg Johnson 联合创立了 New Limit。

Armstrong：科学进展比我想的快。南旧金山有实验室、五六十人：AI 起步——我们造了表观遗传重编程的前沿模型，从海量转录因子组合中推荐下一批实验（巨大搜索空间），然后大规模 pooled screens（在实验室里移原子移液体，不只是软件），命中的做功能测定（动物模型，更贵更慢），最好的进人体试验。我们已在人源化小鼠模型中成功重编程至少一种人类细胞类型，正在非人灵长类测试，明年启动第一个一期临床，未来几年还会有三到十个候选药。

Armstrong：最先攻三种细胞：肝细胞、血管细胞、免疫细胞（尤其 T 细胞）。走 GLP-1 类似路线：先做高未满足需求、有时较小的市场——肝项目一期做酒精性肝病（ALD）：今天他们除肝移植外别无选择、多数等不到，确诊后 12 个月存活率极低；单这个药若成可能值 200 亿美元。但目标不是肝病药：是让 40 岁的人拥有 20 岁的肝、免疫系统、血管，乃至大脑、肌肉、皮肤——皮肤单算可能就是万亿市场。最终你会服用一组鸡尾酒疗法：不同细胞类型、不同载荷，同一主题——把细胞重编程到年轻时的功能。夺走我们生命的多数疾病都与年龄高度相关：年轻时身体能修复癌变细胞与损伤，老了就失去这种能力。与其逐个追症状，不如攻这个元问题——恢复细胞年轻功能，从根上咬一大口。

【认知增强、胚胎编辑与自由城市】

Armstrong：未来五年主线是 Agentic Finance 与稳定币——把加密从 0.5% 的全球 GDP 与 7 亿持有者做到十亿人以上。前沿想法上我最近在想认知增强：给孩子足够叶酸等营养能提高 IQ——也许该办场晚宴聊聊：针对成人、儿童、胚胎的疗法如何拉平认知基线？这是又一个元问题，我还没有好论题——有主意请联系我。我们在与 AI 赛跑：AI 越来越聪明，人类也该在某个时刻接管自己的演化。我投了一家做胚胎编辑的公司 Preventive：人们看过《千钧一发》会紧张，但 Pew 调查显示 80% 美国人支持为防病做胚胎编辑——没人想让孩子得罕见遗传病。今天看似争议，将来会越来越正常，最终不做这种筛查反而异常——像不系安全带开车。

Armstrong：（Elad 问：会不会人人买同一个「智力套餐」、减少神经多样性？）我反而认为会增进多样性：人类偏好的多样性是无限的——伟大的艺术家、将军、工程师、政治家，每个父母偏好不同；而且很多只是抬高底线，孩子还是他自己，只是不再有精神分裂或抑郁症。极限情况下你甚至能得到真正离谱的多样性——有鳃能水下呼吸的孩子、有翅膀能飞的，谁知道接管演化能走多远。

Armstrong：我还超关注特殊经济区——它是能解锁整类进步的元问题。世界许多地方拖慢进步的是过度监管。Coinbase 投资过洪都拉斯的 Prospera 以学习此事。竞选时讨论过「自由城市」：美国联邦政府有大量土地，若认为核能、药物发现、加密、无人机配送对美国战略重要，就划出 10 或 100 平方英里：这里建数据中心、核电站、无限无人机配送都不必过 EPA 与地方审批——在安全可控的范围内实验，跑通了再走正常流程推广。现在的问题是根本没有沙盒去试创新——这极度窒息。深圳、新加坡、迪拜都证明了这类区的威力；美国本就因联邦制是 50 个特殊经济区，还可以更进一步。
